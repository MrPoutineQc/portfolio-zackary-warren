# Technologies

## HTML

- **Tailwind CSS :** Utilisé pour faciliter la mise en place du responsive design et adapter le portfolio aux différentes tailles d'écran.

## JavaScript

- **GSAP :** Utilisé pour créer les différentes animations et interactions du portfolio.
- **ES6 :** Utilisé pour exploiter les fonctionnalités modernes de JavaScript et gérer dynamiquement le contenu à partir de fichiers `.json`.

## CSS

- **SCSS :** Utilisé plutôt que le CSS traditionnel afin de mieux organiser et réutiliser le code grâce aux variables, au nesting et à une meilleure structure des fichiers.
  - **Nesting :** Permet d'imbriquer des sélecteurs CSS à l'intérieur d'autres sélecteurs afin de rendre le code plus clair et mieux organisé.
 
# Choix des 4 technologies

## 1. Gestion des données — Fichier JSON local

J'utiliserais un fichier JSON local, car c'est simple, fiable et fonctionne directement avec GitHub Pages.

## 2. Animations — GSAP

J'utiliserais GSAP pour faciliter la création des différentes animations du site.

## 3. Structure de navigation — One-pager avec pop-up

Les données seront affichées dans le même encadré. L'utilisateur aura simplement à cliquer sur un bouton dans la navbar et, sans changer de page, j'utiliserais des `display: none` pour afficher ou cacher ce qui doit l'être.

## 4. Hébergement — GitHub Pages

Facile et sécuritaire, j'envisage cependant d'acheter un nom de domaine pour plus de professionnalisme.
